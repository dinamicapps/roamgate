# Cerrar el work via runtime (close)

El cierre terminal (estado final + archivado) es deterministico: lo ejecuta el binario `agentos`, no se edita el frontmatter a mano ni existe catalogo que editar. El binario valida la maquina de cierre, bloquea si hay grupos bridge sin archivar (salvo `CANCELADO`), setea `estado` + `fecha_fin` en el README, mueve la carpeta a `works-archivo/{AAAA}/{MM}/{autor-kebab}/{slug}/`, y emite el heartbeat. No hay paso de catalogo: la siguiente lectura (`agentos catalog show`) reconstruye en memoria, encuentra el work en su carpeta nueva y lo reporta archivado con `cerrado_en` + `archivos_tocados` derivados del README, sin que el cierre haya escrito nada de eso explicitamente. Patron de invocacion:

1. **Detectar el binario:** buscar `.claude/agent-os-bin/agentos` (o `agentos.exe` en Windows). Si NO existe: informar "Runtime de agent-os requerido para cerrar el work. Reinstala el runtime de agent-os (instalador del paquete)." y NO cerrar (sin fallback en prosa).
2. **Invocar:** `agentos work close --slug <slug> --estado <TERMINAL>` (TERMINAL: `COMPLETADO` | `COMPLETADO_CON_BRECHA` | `CANCELADO` | `TRASLADADO_A_DISENO` | `REPLANTEADO` | `MIGRADO`). `COMPLETADO_VERIFICACION_DIFERIDA` no esta en la lista porque no se pide: el runtime lo **deriva** de un bloque `verificacion_diferida{}` valido y, en el mismo cierre, appendea su fila al libro-mayor de verificaciones. Ver `piezas/cierre.md` paso 7.
3. **Parsear** `{ok, data}`: si `ok:false`, mostrar `error.mensaje` y detenerse (`CIERRE` si la transicion es ilegal, `BRIDGE` si hay grupos sin archivar); si `ok:true`, continuar.

El trabajo cognitivo del cierre lo gobierna Alfred antes/despues de la invocacion — el binario solo ejecuta el cierre estructural. Las secciones del README (`## Cierre`, `## Archivos modificados`, `## Decisiones clave`) se pueblan via `work file set-section` (JSON `{work_slug, ruta_relativa: "README.md", seccion, contenido}`, una invocacion por seccion): escribir el JSON al scratchpad y pasar `--input <ruta>` es lo recomendado cuando `contenido` lleva prosa larga; stdin sigue siendo valido para secciones cortas. No se edita el README a mano. `## Archivos modificados` debe estar poblada antes de invocar `close` (el binario extrae `archivos_tocados` de ahi). Depositar reflexion ADN, alimentar epica, liberar el rol de sesion en `_sesiones/` y `TaskUpdate` de tareas completan el cierre cognitivo — ver `piezas/cierre.md` flujo completo.
