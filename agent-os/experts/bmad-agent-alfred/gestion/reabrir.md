# Reabrir un work archivado

`agentos work reopen --slug {slug}` — desarchiva un work terminal a EN_PROGRESO (restaura catalogos). Criterios legitimos: cierre por error, rechazo de QA posterior al cierre. NO es la via para "continuar trabajando un poco mas": eso es un work nuevo. La cosecha ya marcada no se revierte (revisar `learn pendientes` tras reabrir).
