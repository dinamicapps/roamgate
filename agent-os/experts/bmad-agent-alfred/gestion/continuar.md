# /alfred continuar [slug]

1. Obtener autor con `git config user.name`.
2. Si se pasa `{slug}`: validar que existe y esta en estado retomable. Si no: leer el catalogo de works, filtrar activos del autor; 0 -> informar; 1 -> retomar; multiples -> `AskUserQuestion`.
3. Leer el README para determinar `ruta`, `estado`, `modo`, punto actual.
4. **Separacion motor-artefacto (CA-11):** un work-record creado por `/work` (formato compartido) puede ser leido por `/alfred continuar` sin conversion. Alfred lee `ruta`, `abordaje{}`, `meta`, `modo`, `nivel` (works legacy de `/work`: `conversacion`, que Alfred deriva a `nivel`) del frontmatter — todos campos del formato compartido (`agent-os/templates/work-record/frontmatter-schema.md`). Alfred ignora los campos que solo usa el motor legacy (`version_sistema`, `etapa_actual`); su ausencia no rompe a Alfred. Si el work fue creado por Alfred, no tiene esos campos legacy y todo funciona igual.
5. **Reanudar el estado (runtime):** si el work esta en una pausa (`PAUSADO`, `EN_PAUSA` o `EN_PAUSA_POR_DISENO`), volver a `EN_PROGRESO` con el binario via `agentos work transition --slug <slug> --a EN_PROGRESO` (ver `gestion/transition.md`). Si el work ya esta `EN_PROGRESO` (sesion abandonada que nunca se pauso), **omitir** la transicion: no se invoca el binario y no es un error. Solo se transiciona si hay una pausa que reanudar.
6. **Works `colaborador-fastrak` (bridge):** un work con `tipo: colaborador-fastrak` nace de una sesion `bridge-session` en la que este repo participa como colaborador con otro Director. No declara `ruta` y su estructura es F0/F1/F2 en lugar del abordaje + E1-E4. Para este `tipo`, `etapa_actual` NO cae bajo la exclusion del paso 4: es el dato que indica el punto pendiente (F0/F1/F2). Se retoma con este mismo comando: si el fastrak aun no existe, entra a `bridge-session` Fase 7 (`agent-os/skills/bridge-session/SKILL.md`); si ya existe (el caso normal de `/alfred continuar`), la reanudacion la gobierna la seccion "Persistencia y continuidad" del mismo SKILL.
7. Activar la pieza/etapa pendiente segun la ruta. Alfred no conduce la conversacion de la pieza: activa al anfitrion.
