# Save Memory

Immediately persist the current session context to memory.

## Process

Update `index.md` with current session context: active audit, findings in progress, pending actions, next steps. Checkpoint `findings-tracker.md`, `patterns.md`, and `chronology.md` if significant changes occurred.

## Output

Confirm save with brief summary: "Memoria guardada. {resumen de lo actualizado}"
