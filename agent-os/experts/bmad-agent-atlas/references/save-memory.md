# Save Memory

Immediately persist the current session context to memory.

## Process

Update `index.md` with current session context: active capability, work in progress, pending items, decisions made, next steps. Checkpoint `patterns.md`, `analysis-log.md`, `project-profile.md`, and `chronology.md` if significant changes occurred during this session.

## Output

Confirm save with brief summary: "Memoria guardada. {brief-summary-of-what-was-updated}"
