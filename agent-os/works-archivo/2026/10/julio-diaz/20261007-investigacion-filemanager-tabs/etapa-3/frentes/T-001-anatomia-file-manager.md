## Contexto de montaje (base comun de las tres tablas)

- El file manager es la vista `files` del Workspace Inspector. `InspectorView` es una union cerrada `"files" | "changes" | "commits" | "history"` (`web/src/workspaceResource.ts:7`). `verificado`.
- Estado del Inspector vive en `App` como `useState<WorkspaceInspectorState | null>` (`web/src/App.tsx:1398`) con ref espejo (`web/src/App.tsx:1400`); su forma (scope, open, view, dock, size, expanded, returnTabId, originPaneId, initialDirectory) esta en `web/src/workspaceResource.ts:96`. `verificado`.
- Entrada unica `openInspector(view, workspaceId, options)` (`web/src/App.tsx:1738`); `openFileExplorer` (`web/src/App.tsx:2154`) y `openFileExplorerFile` (`web/src/App.tsx:2159`) la envuelven con `view = "files"`. `verificado`.
- El host se carga lazy (`web/src/App.tsx:220`) y monta `FileExplorerPanel` (`web/src/components/WorkspaceInspectorHost.tsx:677`) mas `FilePreviewTabs` (`web/src/components/WorkspaceInspectorHost.tsx:725`). `FileExplorerPanel` envuelve `FileExplorerContent` con `showCloseButton={false}` (`web/src/components/FileExplorerDialog.tsx:177`); la logica real esta en `FileExplorerContent` (`web/src/components/FileExplorerDialog.tsx:337`). `verificado`.
- Scope del recurso: `resourceScopeForWorkspace` (`web/src/workspaceResource.ts:150`) produce scope `worktree` (connectionId+repoKey+checkoutKey) o `workspace` (`web/src/workspaceResource.ts:81`). `verificado`.
